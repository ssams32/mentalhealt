# 예산 품의 검수 사용 설명서

ERP에서 작성한 **품의**와 우리가 실제로 쓴 **지출(수기 내역)** 이 서로 맞는지 한 화면에서 확인하는 기능입니다.
엑셀을 따로 펼쳐 놓고 한 줄씩 대조하지 않아도, 맞지 않는 건만 골라서 보여 줍니다.

---

## 1. 들어가는 방법

1. 왼쪽 메뉴에서 **예산 관리**를 누릅니다.
2. 위쪽에서 **연도**(예: 2026년)를 고릅니다.
3. **품의 검수** 탭을 누릅니다.
   - 탭 옆의 **빨간 숫자**는 "확인이 필요한 건수"입니다. 0이 되면 모두 맞은 것입니다.

> 부서별로 보려면 위쪽의 **ALL / 공통 / 회복 / 증진 / 자살 / 남부** 버튼을 누르세요. 검수 화면에도 그대로 적용됩니다.

---

## 2. 먼저 할 일: ERP 품의 엑셀 올리기

검수하려면 ERP 품의 내역이 올라와 있어야 합니다.

1. ERP에서 품의 목록을 엑셀로 내려받습니다.
2. 예산 관리 화면 위쪽의 **UPLOAD** 버튼으로 그 파일을 올립니다.

알아 둘 점
- 엑셀에 **품의번호 · 품의금액 · 예산과목** 열이 꼭 있어야 합니다. 없으면 "업로드를 멈췄습니다. 필수 열(…)을 찾지 못했습니다"라고 나오고 아무것도 바뀌지 않습니다.
- 파일에 들어 있는 **연도만** 새로 바뀝니다. 다른 연도의 품의와 직원이 적은 수기 내역은 그대로 남습니다.
- 새 엑셀을 올릴 때마다 검수 결과가 자동으로 다시 계산됩니다.

---

## 3. 화면 보는 법: 다섯 개의 카드

화면 맨 위에 카드 다섯 개가 있습니다. 카드를 누르면 아래 목록이 그 종류로 바뀝니다.

| 카드 | 뜻 | 해야 할 일 |
|---|---|---|
| 🔴 **품의만 있음** | ERP에 품의는 있는데, 실제 지출 기록이 없음 | 썼으면 **지출로 입력**, 아직 안 썼으면 그대로 둠 |
| 🟡 **지출만 있음** | 지출은 적었는데, 연결된 품의가 없음 | 맞는 품의를 골라 **연결** |
| 🟠 **금액 차이** | 품의 금액과 실제 지출 합계가 다름 | 차액이 맞는지 확인, 잘못 연결됐으면 **연결 해제** |
| 🟢 **일치** | 품의 금액과 지출 합계가 같음 | 할 일 없음 |
| ⚪ **전체 품의** | 이 연도의 ERP 품의 전부 | 참고용 |

카드 아래 숫자는 **건수**와 **금액**입니다. "금액 차이" 카드는 차액을 모두 더한 값을 보여 줍니다.

---

## 4. 상황별 처리 방법

### 4-1. 🔴 품의만 있음

**실제로 돈을 썼는데 기록을 안 한 경우**
- 그 줄 오른쪽의 파란 **지출로 입력** 버튼을 누릅니다.
- 품의의 날짜·금액·적요가 그대로 해당 과목의 수기 내역에 들어가고, 품의와 자동으로 연결됩니다.
- 실제 결제 금액이 품의와 달랐다면, **수기 내역** 탭에서 그 줄의 금액만 고치세요. 그러면 "금액 차이"로 옮겨 가서 차액이 보입니다.

**아직 집행 전인 경우**
- 그대로 두면 됩니다. 지출이 생기면 그때 입력하세요.

**"과목 없음"이라고 나오는 경우**
- 예산 현황에 그 부서·과목이 아직 없다는 뜻입니다. 예산 담당자에게 과목 추가를 요청하세요. 추가되면 버튼이 생깁니다.

### 4-2. 🟡 지출만 있음

1. 그 줄의 **연결할 품의** 칸을 누릅니다.
2. 목록 맨 위 **추천** 묶음에는 같은 과목 중 **금액과 날짜가 가장 가까운 품의**가 먼저 나옵니다. 보통 이미 골라져 있습니다.
3. 맞는 품의인지 확인하고 **연결**을 누릅니다.

- 추천에 없으면 아래 **같은 부서의 다른 품의**에서 고를 수 있습니다. (과목을 잘못 적은 경우 등)
- 맞는 품의가 아예 없다면, ERP에서 품의를 올리지 않은 지출일 수 있습니다. 품의 작성 여부를 확인하세요.

### 4-3. 🟠 금액 차이

- 줄을 누르면 그 품의에 연결된 **지출 목록**이 펼쳐집니다.
- **차액 = 품의금액 − 실사용**
  - **파란 +** : 품의보다 **덜** 쓴 금액(남은 금액)
  - **빨간 −** : 품의보다 **더** 쓴 금액(초과) → 꼭 확인하세요
- 다른 품의의 지출이 잘못 붙어 있으면, 그 지출 옆의 **연결 해제**를 누르세요. 해제된 지출은 "지출만 있음"으로 옮겨 가니, 거기서 맞는 품의에 다시 연결하면 됩니다.

### 4-4. 🟢 일치

- 할 일이 없습니다. 펼쳐서 어떤 지출이 연결됐는지 볼 수 있습니다.

### 4-5. 품의 내역 탭에서 바로 입력하기 (수기 입력 버튼)

품의 검수 탭을 열지 않고, **품의 내역** 탭의 전체 목록에서도 한 번에 입력할 수 있습니다.

1. 예산 관리 → **품의 내역** 탭을 엽니다.
2. 각 품의 줄 오른쪽의 버튼을 봅니다.

| 버튼 | 뜻 | 할 일 |
|---|---|---|
| ⬛ **수기 입력** (검은색) | 아직 수기 내역에 없음 | 누르면 품의의 날짜·금액·작성자·적요가 해당 부서·과목의 수기 내역에 한 줄로 들어갑니다. 적요 앞에 `[품의번호]`가 붙고 품의와 자동으로 연결됩니다. |
| 🟩 **입력됨** (초록색) | 이미 수기 내역에 들어가 있음 | 할 일 없음. 다시 누를 수 없어서 같은 품의가 두 번 들어가지 않습니다. |
| ⬜ **수기 입력** (회색, 눌리지 않음) | 예산 현황에 그 부서·과목이 없음 | 예산 담당자에게 과목 추가를 요청하세요. |

- 품의 검수 탭의 **지출로 입력** 버튼과 같은 기능입니다. 품의 내역 탭은 전체 목록에서, 품의 검수 탭은 아직 입력되지 않은 품의만 모아서 보여 준다는 점만 다릅니다.
- 실제 결제 금액이 품의와 다르면, 입력한 뒤 **수기 내역** 탭에서 금액만 고치세요.
- 같은 날 같은 금액의 품의가 두 건 있어도 각각 따로 입력할 수 있습니다.

---

## 5. 품의 하나를 여러 번에 나눠 쓴 경우

예: 품의 100,000원을 60,000원 + 40,000원 두 번에 나눠 결제

- 두 지출을 **같은 품의에 각각 연결**하세요.
- 합계(100,000원)로 비교하므로 "일치"가 됩니다.
- 한 번만 연결하면 "금액 차이 +40,000원"으로 보이니, 나머지 지출도 연결했는지 확인하는 데 쓸 수 있습니다.

---

## 6. 자동으로 연결되는 경우

아래 경우에는 직원이 따로 연결하지 않아도 자동으로 짝지어집니다.

1. **지출로 입력** 버튼으로 넣은 지출
2. 수기 내역의 내용(적요)에 **[품의번호]** 를 적은 지출 (예: `[20260305-002] 간담회 다과`)
3. **부서 · 과목 · 날짜 · 금액이 모두 같은** 지출 (품의 하나당 한 건만 자동 연결)

자동 연결이 틀렸다면 **연결 해제**를 누르면 됩니다. 한 번 해제한 지출은 다시 자동으로 붙지 않습니다.

> 펼친 지출 목록 오른쪽의 작은 글씨로 어떻게 연결됐는지 볼 수 있습니다.
> **직접 연결** / **품의번호 표기** / **날짜·금액 자동**

---

## 7. 원하는 것만 골라 보기

- **부서**: 화면 위쪽 부서 버튼
- **월**: "전체 월" 칸에서 월 선택
- **검색**: 품의번호, 적요, 과목, 작성자 일부를 입력

---

## 8. 확인 필요 목록 엑셀로 받기

**확인 필요 목록 엑셀** 버튼을 누르면 "일치"를 뺀 나머지(품의만 있음, 지출만 있음, 금액 차이)가 엑셀로 내려받아집니다.
고른 부서·월·검색 조건이 그대로 적용되므로, 회계 담당자에게 전달하거나 결재 자료로 쓸 수 있습니다.

---

## 9. 월말 점검 순서 (권장)

1. ERP에서 이번 달까지의 품의 엑셀을 내려받아 **UPLOAD**
2. **품의 검수** 탭 → **월**에서 이번 달 선택
3. 🟡 **지출만 있음** → 모두 품의에 연결 (또는 품의 누락 확인)
4. 🔴 **품의만 있음** → 실제 쓴 건은 **지출로 입력**
5. 🟠 **금액 차이** → 빨간 −(초과) 건부터 확인
6. 빨간 숫자가 남은 건은 **확인 필요 목록 엑셀**로 받아 담당자에게 전달

---

## 10. 자주 묻는 질문

**Q. 연결하거나 해제하면 바로 저장되나요?**
네. 버튼을 누르는 즉시 서버에 저장됩니다. 화면 아래에 "연결했습니다 / 해제했습니다" 안내가 뜹니다.

**Q. 연결 해제하면 지출 기록이 지워지나요?**
아니요. 품의와의 연결만 끊어지고, 지출 기록은 그대로 남습니다.

**Q. 엑셀을 다시 올리면 연결이 풀리나요?**
아니요. 연결은 품의번호로 기억하므로, 같은 품의번호가 다시 올라오면 그대로 이어집니다.

**Q. 다른 연도 자료도 섞여 나오나요?**
아니요. 위쪽에서 고른 연도의 품의와 지출만 비교합니다.

**Q. 직원이 "지출 내역 추가" 버튼으로 넣은 공통 지출은요?**
그 항목은 품의 검수 대상에서 빠집니다. 과목별 수기 내역에 적은 지출만 비교합니다.
